QUICK START (3 Steps)
────────────────────────────────────────────────────────────────────────────

1. Generate a driver project:
   $ python3 driver_generator.py MyTestDriver ./MyDriver

2. Navigate to project and review documentation:
   $ cd MyDriver
   $ cat README.md

3. Build and test (Windows + WDK required):
   $ python build.py


DETAILED USAGE
────────────────────────────────────────────────────────────────────────────

SYNTAX:
  python3 driver_generator.py <project_name> [output_directory]

ARGUMENTS:
  project_name       - Name of your driver project (required)
  output_directory   - Where to create the project (optional, default: ./project_name)

EXAMPLES:
  # Basic usage
  python3 driver_generator.py TestDriver

  # Specify output directory
  python3 driver_generator.py TestDriver ./output

  # Generate to specific path
  python3 driver_generator.py MyAC /home/user/projects/MyAC

BUILDING THE GENERATED PROJECT
────────────────────────────────────────────────────────────────────────────

REQUIREMENTS (Windows only):
  - Windows 10/11 (64-bit)
  - Visual Studio 2019/2022
  - Windows 11 SDK
  - Windows Driver Kit (WDK)
  - CMake 3.15+
  - Python 3.7+

BUILD STEPS:
  1. Navigate to generated project:
     $ cd MyDriver

  2. Run automated build:
     $ python build.py

  3. Or build manually:
     # Usermode:
     $ mkdir build && cd build
     $ cmake ..
     $ cmake --build . --config Release

     # Driver (requires WDK):
     $ cd driver
     $ msbuild driver.vcxproj /p:Configuration=Release /p:Platform=x64


INSTALLING & RUNNING
────────────────────────────────────────────────────────────────────────────

1. Enable test signing (one-time):
   > bcdedit /set testsigning on
   (Reboot required)

2. Load the driver:
   > sc create MyDriver type= kernel binPath= C:\path\to\driver.sys
   > sc start MyDriver
   > sc query MyDriver

3. Run usermode application:
   > cd build\Release
   > AntiCheatTester.exe MyDriver

TROUBLESHOOTING
────────────────────────────────────────────────────────────────────────────

"Python syntax error"
  → Ensure you have Python 3.7+
  → Run: python3 --version

"Generation failed"
  → Check you have write permissions
  → Try different output directory
  → Review error messages

"Build failed" (on Windows)
  → Verify all prerequisites installed
  → Check WDK and SDK versions match
  → Run build from WDK command prompt

"Driver won't load"
  → Enable test signing: bcdedit /set testsigning on
  → Reboot after enabling test signing
  → Run as Administrator
  → Check Event Viewer for errors
